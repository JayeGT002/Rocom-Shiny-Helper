# Rocom-Shiny-Helper

洛克王国赛季异色属性池匹配工具。纯前端单页应用：勾选目标异色精灵，自动匹配最优的「推荐属性池」，并按属性池分组标注可定向方式（属性池定向 / 赛季机制定向 / 不可定向）。

在线访问：`https://jayeGT002.github.io/Rocom-Shiny-Helper/`

## 结构

```
.
├── index.html        # 主页面（唯一入口）
├── data/             # 赛季数据（S1~S5 等 JSON 配置）
└── images/           # 精灵立绘 / 属性图标 / 星光值图标
```

## 本地预览

```bash
python -m http.server 8080
```
